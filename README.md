# Paradise Nursery 🌿

A React front-end shopping application for browsing and buying houseplants.  
Built as the final project for the Coursera course *Developing Front-End Apps with React*.

## Features

- **Landing Page** with company introduction and background image
- **Product Listing** – 6+ plants in 3 categories, with Add to Cart functionality
- **Shopping Cart** – Adjust quantities, remove items, view total cost
- **State Management** using Redux Toolkit
- **Responsive** design with React Router navigation

## Tech Stack

- React (Vite)
- React Router
- Redux Toolkit
- CSS
